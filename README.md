## 運用ルール
- デイリーノートの原本は削除しない。振り分けた内容は移動先ノートに残し、デイリーノート側には注記・リンクは付けない
- 移動先ノートには、各トピックの文末にイタリック体で日付を添える（例: `- 内容 *(2026-07-24)*`）。日付を見出しにはしない
- Vaultは`.git`管理下にない（ユーザーの意向でバックアップ目的のgit導入はしない）
- 詳細は `.claude/skills/obsidian-organize/SKILL.md` を参照
