# タグ・リンク整理 手順

Vault内ではタグ・wikilink・frontmatterがごく一部でしか使われていない。既存の少ない用例から自然にルールを見出し、押し付けにならない範囲で整理する。

## 手順

1. **現状調査**
   - `Grep`で `#[^\s#]+` を検索し、既存タグの使用例と表記ゆれ（例: `#AI` と `#ai`、`#機械学習` と `#ML`）を洗い出す。
   - `Grep`で `\[\[.*?\]\]` を検索し、既存wikilinkの使用状況を確認する。
   - 対象範囲（フォルダ指定など）はユーザー指定があればそれに従い、なければ「タグ・リンクが薄い主要トピックフォルダ」を優先候補として提示する。

2. **タグの統一（依頼された場合）**
   - 表記ゆれを1つの正規化候補にまとめて提示する（例: `#AI`, `#ai` → `#AI` に統一）。判断が割れそうなものはユーザーに確認する。
   - 統一後のタグ一覧を提示してから一括置換する。

3. **バックリンク（wikilink）の付与**
   - 同一トピックフォルダ内、または内容的に関連するノート同士を`Grep`のキーワード一致や見出し・タイトルの類似で洗い出す。
   - 関連が明確なペアのみ、双方向、または少なくとも片方から`[[ノート名]]`形式でリンクを追加する。無理にリンクを増やさない（本文の文脈上自然な箇所にのみ挿入する）。
   - リンクを追加する変更一覧をユーザーに提示してから実行する。

4. **MOC（Map of Content）の作成（依頼された場合、または明らかに有用な場合のみ提案）**
   - 1フォルダにノートが増えて見通しが悪い場合、そのフォルダ用の索引ノート（例: `LLM/LLM_MOC.md`）を作り、配下ノートへのwikilink一覧を作る。
   - 既存の命名規則（`Rules/notetitle_rules.md`）に従った名前にする。
   - MOCを作るかどうかは提案してユーザーの合意を得てから作成する（自動生成物を無断で増やさない）。

5. **サマリー報告**
   - 統一したタグ、追加したリンク、作成したMOCを一覧で報告する。
